# Портфолио UX/UI-дизайнера

Первый экран портфолио. При прокрутке обложки выходят из стопки по очереди.

Открой `index.html` в браузере, чтобы посмотреть страницу локально. Для GitHub Pages выбери ветку `main` и папку `/ (root)` в **Settings → Pages**.

## Как заменить обложки

Картинки лежат в `assets/`. Порядок показа — «Telegram mini app», «Дизайн система», «Лендинг и сервис по подбору участка», «Лендинг и онлайн сметы на строительство». Чтобы заменить картинку, сохрани её под тем же именем или обнови `src` у нужной карточки в `index.html`. Подпись задаётся в `data-title`. Если меняешь название первой карточки, обнови и начальную подпись под обложкой.

Чтобы активировать кнопку «Смотреть проект», добавь к нужной обложке в `index.html` атрибут `data-project-url` с адресом проекта. Адрес первого проекта также укажи в `href` самой кнопки. Кейс Telegram mini app открывается в `telegram-mini-app.html` со встроенной публикацией Behance.

За размеры, позиции и скорость движения отвечают `styles.css` и `scroll.js`.

Меню в шапке раскрывает подпись выбранного пункта и перемещает подсветку с анимацией по мотивам [Bottom Bar](https://designbookmark.com/motion#db-bottom-bar). Пружины меню настроены в `header-menu.js`.

Раздел «Обо мне» открывается из шапки и при прокрутке после портфолио. Физика тегов адаптирована из [Skill Pills Tray от Animorio](https://animorio.com/en/animations/designer-profile-with-skills-in-a-tray-that-tilts/). Текст и теги можно обновить в `index.html`.

В разделе «Контакты» ссылка и QR-код ведут в Telegram.
